Ecowitt and MeteoPulse

MeteoPulse provides an Ecowitt connection method for compatible station setups. Sensor availability and historical coverage can vary with the station, hardware and connection method. MeteoPulse is an independent application and is not an official Ecowitt app or affiliated with Ecowitt.

For connection instructions, see the Ecowitt section of the MeteoPulse manual. For a deeper look at long-term data, visit Personal Weather Station History.

Frequently asked questions

Does MeteoPulse work with Ecowitt?

MeteoPulse includes an Ecowitt connection method for compatible station setups. Compatibility can depend on the station and available data, so MeteoPulse does not claim support for every Ecowitt model.

Can I see historical rainfall?

MeteoPulse includes rainfall and historical views using the data available for the connected station. Historical coverage depends on the connection method and data that MeteoPulse can access.

Can I track wind gust records?

Yes, MeteoPulse can show wind and gust information and records based on the observations available for the selected station.

Does MeteoPulse support metric and imperial units?

MeteoPulse includes unit settings in versions where those options are available. The app internally handles weather measurements so they can be presented using the supported unit preference.

Is MeteoPulse available for Android?

Yes. MeteoPulse has an Android application. The public Google Play listing link will be added here once its public production URL is confirmed.
