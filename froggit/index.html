Connecting a compatible Froggit setup

MeteoPulse supports connection workflows that can be used with compatible Froggit station hardware. One verified project setup uses a Froggit HP2000-family console through MeteoPulse's direct/custom-server workflow. This does not mean every Froggit model or firmware is supported.

Custom-server menus and protocol names can vary by console and firmware. Always follow the values shown by MeteoPulse for the station you are adding. See the direct connection guide for the current setup process.

Frequently asked questions

Does MeteoPulse work with every Froggit weather station?

No universal compatibility claim is made. Compatibility depends on the station hardware, firmware and available connection method.

What can I analyse in MeteoPulse?

Depending on the data available from the connected station, MeteoPulse provides live weather, rainfall, wind, historical information, statistics, records and weather-map views.

Can a Froggit station send data directly to MeteoPulse?

A direct/custom-server workflow has been verified with a compatible Froggit HP2000-family setup. Other models should not be assumed compatible without verification.

Can I use MeteoPulse to review weather history?

Yes, where historical observations are available to MeteoPulse. Learn more on the weather station history page.
