Connecting a compatible Froggit setup

MeteoPulse supports connection workflows that can be used with compatible Froggit station hardware. One verified project setup uses a Froggit HP2000-family console through MeteoPulse's direct/custom-server workflow. Custom-server menus and protocol names can vary by console and firmware.

Compatibility note. This verified HP2000-family workflow does not mean every Froggit model or firmware is supported. MeteoPulse is an independent application and is not an official Froggit app or affiliated with Froggit.

Always follow the parameters shown by MeteoPulse for the station you are adding. See the direct connection guide for the setup process.

Frequently asked questions

Does MeteoPulse work with every Froggit weather station?

No universal compatibility claim is made. Compatibility depends on station hardware, firmware and the available connection method.

Can a Froggit station send data directly to MeteoPulse?

A direct/custom-server workflow has been verified with a compatible Froggit HP2000-family setup. Other models should not be assumed compatible without verification.

Is MeteoPulse available for Android?

Yes. MeteoPulse is available on Google Play.
